# Простой Калькулятор

## Как открыть проект:
1. Запустите Android Studio
2. Нажмите **File → Open**
3. Выберите папку `c:\Users\Ivan\MD`
4. Дождитесь синхронизации Gradle

## Запуск:
1. Создайте эмулятор (**Tools → Device Manager**)
2. Нажмите **Run** (зелёный треугольник) или `Shift + F10`

---

## Инструкция по работе с калькулятором

### Кнопки:
| Кнопка | Описание |
|--------|----------|
| **0–9** | Ввод цифр |
| **+ − × ÷** | Операции (сложение, вычитание, умножение, деление) |
| **=** | Вычислить результат |
| **C** | Очистить всё (сброс) |
| **.** | Десятичная точка |

### Примеры использования:

**Простое сложение:**
```
5 + 3 =  →  8
```

**Цепочка операций:**
```
5 + 3 × 2 =  →  16
```

**Деление:**
```
10 ÷ 4 =  →  2.5
```

**Отрицательный результат:**
```
5 − 10 =  →  -5
```

**Деление на ноль:**
```
5 ÷ 0 =  →  Ошибка
```

### Особенности:
- Поддержка десятичных дробей (например, `3.14`)
- Автоматическое удаление лишних нулей (`2.500` → `2.5`)
- При повороте экрана значение сохраняется
- Экран всегда в портретном режиме
